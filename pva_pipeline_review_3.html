PVA (Posh Authenticate Virtual) 파이프라인 — 정책·스펙 갭 리뷰

확정된 주요 스펙

  • [리스팅 등록] 필수 인증 포인트 사진이 없으면 등록 자체가 안 됨
  • [인증 비용] 바이어에게 무료로 제공 (경쟁사 벤치마킹 후 유료→무료로 전환됨)
  • [진위 판정] 최종 판단은 사람(PA 심사팀)이 하고, AI는 사전 스크리닝만 보조함
  • [반품 검증] 반품 시 인증 포인트를 다시 촬영해서 원본과 비교하는 로직

부족한 것

  • [UI] 실제 화면·문구 스펙이 거의 없음 — 쇼퍼·셀러 어느 화면에 뭘 추가해야 하는지가 정의된 게 없음
  • [정책] 검수 실패·반품 이후 처리(환불, 책임 소재, 페널티)가 전 구간 공통으로 없음
  • [정책] Verified Seller 승급·강등 기준, 이의제기 절차 없음

Hyom 제안

  • [정책] Verified Seller 승급·강등에 필요한 정책이 아직 없어 보임
  • [UI] "verified"는 판정 전인데도 이미 인증된 것처럼 오해를 줄 수 있어, 배지 문구를 "~대상 / ~프로그램" 톤으로 조정 필요
  • [파이프라인] 인증 신호를 검색 랭킹에도 연동
